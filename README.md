# 🏙️ NagarVaani - नगरवाणी

**Your Voice, Your Government** | **अपनी आवाज, अपनी सरकार**

NagarVaani is a comprehensive GovTech platform that enables citizens to report civic issues in their native language and track resolution in real-time. The system uses AI for translation, categorization, and assignment, making governance accessible to all.

---

## ✨ Key Features

### 👥 Citizen Features
- **🌐 Multilingual Support** - 12+ Indian languages (Hindi, Marathi, Tamil, Telugu, Bengali, etc.)
- **🎤 Voice-to-Text** - For low-literacy users using Web Speech API
- **📍 Location Picker** - Manual entry or GPS-based detection
- **📎 File Upload** - Attach photos/documents up to 10MB
- **🤖 AI Processing** - Auto-detects language, translates, sets priority
- **📱 Real-time Tracking** - WhatsApp-style timeline with officer notes
- **📱 QR Code Sharing** - Share complaint status via QR
- **👁️ Public Feed** - Anonymous view of area-wise issues

### 🏛️ Officer Features
- **📋 Officer Dashboard** - View assigned complaints with filters
- **✅ Complaint Management** - Accept/reject, update status, add notes
- **⏰ SLA Timer** - Track resolution deadlines with alerts
- **📎 Proof Upload** - Attach resolution proof
- **🔄 Assignment System** - Department heads can assign to officers
- **⚠️ Escalation** - Flag overdue complaints

### 👑 Admin Features
- **📊 Super Admin Panel** - Full system overview
- **👥 Officer Management** - Add, edit, remove officers
- **📈 Department Analytics** - Performance metrics by department
- **📤 Bulk Operations** - Update multiple complaints, export data
- **🔄 Override System** - Reassign complaints manually

### 📊 Analytics Dashboard
- **🥧 Category Distribution** - Pie/Donut charts
- **📈 Trend Analysis** - Complaints over time 
- **⏱️ Resolution Time** - Average time by department
- **🗺️ Heatmap** - Complaint volume by ward/area
- **📊 Performance Metrics** - Officer scorecards
